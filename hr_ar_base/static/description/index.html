RRHH Base Argentina

Argentina-specific HR features, starting with employee CUIT/CUIL

Adds a CUIT/CUIL field to the employee form, validated and formatted with the same criteria Odoo already uses for the VAT field of Argentine Customers/Vendors, and warns (without blocking) when another employee in the same company already has the same number.

This module is meant to grow with more Argentina-specific HR features over time.
